# RESUMO COMPLETO - PROJETO CHIQUE ELÉTRICO

## ESTRUTURA GERAL DO PROJETO
**Objetivo**: Site completo para loja de materiais elétricos "Chique Elétrico" com 5 páginas HTML interconectadas.

**Cores Obrigatórias**: 
- Fundo: #2277DD
- Texto: #FFEE44  
- Links: #FFEE55
- Links Visitados: #FFEE33

**Arquivos Necessários**:
- ChiqueEletrico.html (página inicial com tabelas)
- Página HTML5 com CSS externo
- Materiais.html (listas de produtos)
- Acabamentos.html (tabela com células mescladas)
- Pedidos.html (formulário complexo)
- styles.css (arquivo CSS externo)

## PÁGINA 1 - LAYOUT COM TABELAS (ChiqueEletrico.html)
**Estrutura**: Tabela invisível (border=0) para posicionamento
**Fontes**: Verdana/Ubuntu (menu/endereço), Lucida Bright/Liberation (texto principal)
**Menu**: Lista não numerada (square bullets), links abrem nova janela
**Links**: ChiqueEletrico.html, Materiais.html, Acabamentos.html, Pedidos.html
**Elementos**: 
- Logo LogoChiqueEletricoTopo.png (canto superior esquerdo)
- HR 320px abaixo do logo
- Tag <address> para informações de localização
- LogoChiqueEletrico.png centralizado com texto

## PÁGINA 2 - HTML5 SEMÂNTICO + CSS
**Tags obrigatórias**: header, nav, section
**CSS externo obrigatório**: sem atributos inline
**Fontes**: Google Fonts "Karla" e "Stoke" + "verdana", "ubuntu", "Lucida Bright", "liberation"
**Classes criadas**: ender, imgLogo, apres

**CSS Estrutural**:
```css
header { display: block; margin-bottom: 1px; }
nav { display: block; width: 20%; float: left; }
section { display: block; width: 70%; float: right; }
```

**Classes CSS**:
- **body**: #2277DD fundo, #FFEE44 texto, 16px, fontes stoke/Lucida Bright/liberation
- **a**: sem sublinhado, #FFEE55 links, #FFEE33 visitados
- **ol/ul**: line-height 200%
- **ender**: float right, texto direita, line-height 140%, 14px, fontes Karla/Verdana/Ubuntu
- **imgLogo**: borda inferior 3px #FFFFFF, margin-bottom 6px, padding-bottom 10px
- **apres**: text-align center, 16px
- **nav ul**: #FFEE44, line-height 230%, margin-top 40px, list-style square

## REQUISITOS CRÍTICOS
1. **Navegação**: Todos os links devem funcionar entre páginas
2. **Atributo name**: Obrigatório em TODOS elementos de formulário
3. **Google Fonts**: Importar Karla e Stoke via CSS
4. **Responsividade**: Não obrigatória, mas layout deve funcionar
5. **Imagens**: Dimensões específicas respeitadas (60x44px para produtos)
6. **Readonly**: Aplicado onde especificado no formulário
7. **Target="_blank"**: Links abrem nova janela/tab
8. **Cores exatas**: Usar códigos hex específicos fornecidos
